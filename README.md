# 수능핏 (SuneungFit) — 수능 점수 기반 대학 추천 플랫폼

수능 영역별 점수(표준점수·백분위·등급·선택과목)를 입력하면 대학·모집단위별 정시 반영비율과 가산점/감점 기준에 따라 환산 점수를 계산하고, **가·나·다군별 지원 가능 대학(`안정` · `적정` · `소신` · `상향`)**을 실시간 추천해 주는 웹 플랫폼입니다.

## 주요 기능

- **수능 성적 입력 & 프리셋**: 국어·수학·탐구1·탐구2(표준점수/백분위/등급/선택과목) 및 영어·한국사 등급 입력, 4종 대표 성적 프리셋 제공
- **대학별 정시 환산 엔진**: 표준점수형/백분위형 구분, 국·수·영·탐 반영 비율, 영어 등급 환산표/감점제, 한국사 감점, 미적분·기하 및 과탐 가산점, 탐구 1과목/2과목 반영, 필수 응시과목(`지원제한`) 판정
- **모의 지원 포트폴리오**: 가군·나군·다군 각 1개 학과씩 담아 3장 지원 조합 밸런스 자동 진단
- **상세 환산 분석 모달**: 예상 소신/적정/안정 컷 라인 대비 내 환산점수 위치, 영역별 기여 점수, 유불리 코멘트 확인
- **추천 API 엔드포인트**: `POST /api/recommend`

## 기술 스택

- Next.js 16 (App Router, TypeScript)
- React 19
- Tailwind CSS v4
- `lucide-react`

## 로컬 실행 및 검증

```bash
npm install
npm run dev       # 개발 서버 실행 (http://localhost:3000)
npm test          # 환산 및 판정 로직 단위 테스트
npm run lint      # ESLint 검사
npm run build     # 프로덕션 빌드 검증
```
